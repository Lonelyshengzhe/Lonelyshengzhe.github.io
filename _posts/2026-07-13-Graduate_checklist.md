# 荷兰留学生毕业离境 Checklist

> 适用于毕业后离开荷兰、回国或迁往其他国家的国际学生。  
> 建议在预计离境前 **4–8 周**开始处理，并保留所有注销、退租和退款凭证。

<div id="graduate-checklist-progress"></div>

---

## 0. 关键日期与信息

在开始办理前，先填写以下信息：

|项目|日期／信息|
|---|---|
|正式毕业日期||
|租约结束日期||
|房屋交接日期||
|向市政府申报的离境日期||
|实际航班日期||
|居留卡到期日期||
|离境后的海外地址||
|离境后的常用邮箱||
|可长期使用的手机号码||

## 执行原则

1. **先确定毕业、退租和航班日期，再办理注销。**
    
2. 所有取消合同、归还物品和地址变更尽量通过邮件或在线系统完成，保留书面记录。
    
3. 不要在收到押金、能源退款和税务结算前过早关闭荷兰银行账户。
    
4. 不要在最后一次离开申根区之前剪毁或寄回居留卡。
    
5. DigiD、MijnOverheid 和个人邮箱应至少保留到离境后一年。

# 第一阶段：离境前 1–2 个月

## 1. 学校与毕业文件

### 执行指引

确认学校系统中已经完成毕业申请，而不仅是提交论文或获得最后一门课程成绩。联系项目的 Education Desk，确认正式毕业日期、毕业证领取方式以及成绩单和毕业证明的获取方式。

若正式毕业证无法在离境前取得，应提前确认：

- 是否可以邮寄到海外；
    
- 是否可以授权他人代领；
    
- 是否可以先取得 graduation statement；
    
- 是否需要认证副本、翻译或 apostille。
    

同时将学校邮箱、云盘、Canvas 和其他学习平台中的资料下载到个人设备。

### Checklist

- [ ] 确认所有学分、论文成绩和毕业要求已完成
    
- [ ] 完成正式毕业申请
    
- [ ] 确认 official graduation date
    
- [ ] 确认毕业证领取或海外邮寄方式
    
- [ ] 下载最终成绩单和临时毕业证明
    
- [ ] 备份论文、课程资料和学校邮件
    
- [ ] 归还图书馆书籍、门禁卡及学校物品
    
- [ ] 确认学校账户和邮箱的停用时间
    

---

## 2. 学历认证与回国使用

### 执行指引

先向未来学校、雇主或学历认证机构确认具体要求，不要默认所有文件都需要 apostille。

常见材料包括：

- 毕业证；
    
- 最终成绩单；
    
- graduation statement；
    
- certified copy；
    
- 荷兰学历数字摘录；
    
- 翻译件；
    
- apostille。
    

若需要在荷兰完成文件认证，应尽量在离境前开始办理；若毕业证尚未签发，则确认能否委托他人处理。

### Checklist

- [ ] 确认国内学校或雇主需要哪些学历材料
    
- [ ] 确认是否需要 certified copy、翻译或 apostille
    
- [ ] 确认毕业证未签发时的替代证明
    
- [ ] 保存所有认证材料和寄送记录
    
- [ ] 毕业后检查 Mijn DUO 中是否已有学历记录
    

---

## 3. 房屋退租

### 执行指引

检查租约中的 notice period，按要求向房东或住房公司提交书面退租通知，并预约预检查和最终检查。

退房前应拍摄完整照片和视频，尤其是墙面、地板、家具、厨房、浴室以及水电表。交钥匙时尽量取得书面的 inspection report 或交接确认。

押金退款必须确认：

- 退款金额；
    
- 可能的扣款项目；
    
- 预计退款日期；
    
- 收款银行账户。
    

### Checklist

- [ ] 按租约要求提交书面退租通知
    
- [ ] 预约房屋预检查和最终检查
    
- [ ] 完成清洁、维修和家具处理
    
- [ ] 拍摄房屋状态及水电表读数
    
- [ ] 完成交钥匙并取得书面确认
    
- [ ] 向房东提供押金退款账户
    
- [ ] 保存租约、检查报告和退房照片
    

---

## 4. 合同与订阅

### 执行指引

整理银行账单中的自动扣款项目，逐一确认终止日期。不要只取消 direct debit，而应正式通知服务商结束合同。

部分服务可能有一个月通知期，因此应提前处理。

### Checklist

- [ ] 取消或转移电力、燃气和供水合同
    
- [ ] 取消网络和手机套餐
    
- [ ] 取消健身房、自行车、NS Flex 等订阅
    
- [ ] 关闭 OV-chipkaart 自动充值
    
- [ ] 取消不再需要的软件和媒体订阅
    
- [ ] 保存合同终止确认和最终账单

# 第二阶段：离境前 2–4 周

## 5. 市政府注销与海外地址

### 执行指引

永久离开荷兰或未来一年内大部分时间居住在国外时，应向所在城市的 gemeente 办理 BRP 注销。

办理时通常需要：

- 护照或身份证件；
    
- 当前荷兰地址；
    
- 正式离境日期；
    
- 离境后的海外地址。
    

建议在仍位于荷兰时完成，并保存 deregistration confirmation。注销后 BSN 通常仍然保留，个人信息转入非居民登记。

### Checklist

- [ ] 确定正式申报的离境日期
    
- [ ] 向 gemeente 办理 BRP 注销
    
- [ ] 登记离境后的海外地址
    
- [ ] 保存注销确认或 RNI 记录
    
- [ ] 海外地址变化后及时更新登记信息
    

---

## 6. 居留许可与 IND

### 执行指引

确认居留卡的到期日以及毕业后允许停留的期限。不要仅以毕业典礼日期判断居留是否有效。

完成最后一次离开申根区后，按照 IND 要求归还居留卡。邮寄前通常需要使卡片失效，并保留卡片照片和邮寄凭证。

### Checklist

- [ ] 确认正式毕业日期与居留许可截止日期
    
- [ ] 确认最后一次离开申根区的日期
    
- [ ] 离境后按要求归还居留卡
    
- [ ] 保存居留卡正反面照片
    
- [ ] 保存邮寄或现场归还凭证
    

---

## 7. 医疗保险与补贴

### 执行指引

先确认自己购买的是荷兰基础医疗保险，还是国际学生私人保险。向保险公司提交离境或注销证明，并要求书面确认保险终止日期。

若领取过 zorgtoeslag 或 huurtoeslag，应进入 Mijn Toeslagen 检查结束日期，避免离境后继续收到补贴而产生追缴。

### Checklist

- [ ] 确认当前保险类型
    
- [ ] 向保险公司申请正式终止保险
    
- [ ] 提交所需的注销或离境证明
    
- [ ] 检查 zorgtoeslag 是否结束
    
- [ ] 主动停止 huurtoeslag
    
- [ ] 保存保险终止证明和最终结算单
    

---

## 8. DigiD 与政府账户

### 执行指引

离境后仍可能需要处理税务、补贴、学历和政府信件，因此必须确保 DigiD 在海外可以正常使用。

若准备停用荷兰手机号，应先更新 DigiD 和银行绑定号码。建议在离境前完成 DigiD app 激活和身份验证。

### Checklist

- [ ] 确认 DigiD 用户名和密码可用
    
- [ ] 激活并测试 DigiD app
    
- [ ] 在停用旧号码前更新绑定手机号
    
- [ ] 测试 MijnOverheid、Mijn DUO 和税务账户
    
- [ ] 开启 Berichtenbox 邮件提醒
    
- [ ] 更新常用邮箱和海外联系方式
    

---

# 第三阶段：离境前最后一周

## 9. 银行与财务

### 执行指引

向银行更新海外地址、手机号和税务居住信息。建议暂时保留荷兰银行账户，用于接收：

- 房屋押金；
    
- 水电能源退款；
    
- 保险退款；
    
- 税款退款；
    
- 补贴最终结算。
    

下载需要长期保存的 bank statements 和年度报表，并确认银行 App 在国外仍能登录。

### Checklist

- [ ] 更新银行中的海外地址和手机号
    
- [ ] 下载银行流水和年度报表
    
- [ ] 测试银行 App 和身份验证
    
- [ ] 保留足够余额支付最终账单
    
- [ ] 暂不关闭用于接收退款的银行账户
    

---

## 10. 税务资料

### 执行指引

离境当年通常仍需在下一年度完成荷兰税务申报。将工资、实习、奖学金、银行、保险和补贴文件集中保存。

确保税务机关能够通过 RNI 地址、MijnOverheid 或电子邮箱联系到你。

### Checklist

- [ ] 保存工资单和 jaaropgave
    
- [ ] 保存银行、保险和补贴年度材料
    
- [ ] 保存实习或其他收入记录
    
- [ ] 检查是否有未缴税款或政府账单
    
- [ ] 记录下一年度税务申报事项
    

---

## 11. 行李与个人物品

### 执行指引

提前处理无法带走的家具、自行车、电器和生活用品。贵重物品、毕业文件和身份证件应随身携带，不建议放入托运行李或海运箱。

若寄送国际包裹，应保存装箱清单、申报价值、快递单号和保险信息。

### Checklist

- [ ] 出售、捐赠或丢弃不带走的物品
    
- [ ] 安排国际快递或额外托运行李
    
- [ ] 准备重要文件随身包
    
- [ ] 整理药品、处方和医疗资料
    
- [ ] 保存国际包裹追踪信息
    

---

# 第四阶段：离境当天

## 12. 房屋最终交接

### Checklist

- [ ] 拍摄房间和公共区域的最终状态
    
- [ ] 拍摄水、电、燃气表读数
    
- [ ] 完成交钥匙和 final inspection
    
- [ ] 清空信箱、储物间和自行车库
    
- [ ] 确认门铃和信箱上的姓名已移除
    
- [ ] 保存房东或住房公司的联系方式
    

---

## 13. 随身文件检查

### Checklist

- [ ] 护照
    
- [ ] 居留卡
    
- [ ] 机票和行程单
    
- [ ] BRP 注销证明
    
- [ ] 毕业证明或成绩单
    
- [ ] 房屋退租和交接证明
    
- [ ] 保险终止证明
    
- [ ] 银行和税务重要信息
    
- [ ] 药品、处方及医疗文件
    
- [ ] 重要联系人和紧急联系方式
    

---

# 第五阶段：离境后 1–6 个月

## 14. 离境后跟进

### 执行指引

回国后仍需定期查看 MijnOverheid、邮箱和银行账户。建议至少每两周检查一次，直到押金、保险、能源和补贴全部结算。

对于尚未完成的毕业证寄送、学历认证和税务事项，建立单独的跟进记录。

### Checklist

- [ ] 确认 BRP 已成功注销
    
- [ ] 完成 IND 居留卡归还
    
- [ ] 跟进房屋押金退款
    
- [ ] 跟进水电、保险和其他退款
    
- [ ] 检查毕业证和成绩单寄送状态
    
- [ ] 下载 Mijn DUO 学历记录
    
- [ ] 定期查看 MijnOverheid Berichtenbox
    
- [ ] 完成下一年度荷兰税务申报
    
- [ ] 所有结算完成后再考虑关闭银行账户
    

---

# 最终完成确认

只有在以下项目全部完成后，才建议将离境事务标记为结束：

- [ ] 学校毕业手续与毕业文件已落实
    
- [ ] 房屋已交接，押金已收到或扣款已确认
    
- [ ] BRP 已注销，海外地址登记正确
    
- [ ] 居留卡已归还 IND
    
- [ ] 医疗保险和补贴已经终止
    
- [ ] 所有生活合同和订阅已经取消
    
- [ ] 水电、保险和政府账单已经结清
    
- [ ] DigiD、MijnOverheid 和银行账户可在海外使用
    
- [ ] 下一年度税务申报已经记录或完成
    
- [ ] 所有重要文件已完成本地与云端备份
